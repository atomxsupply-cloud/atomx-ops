# Contexto del equipo

Esta carpeta recoge información para que el bot interno entienda mejor cómo habla y trabaja el equipo.

## Objetivo

Dar contexto real sobre:

- tono
- vocabulario
- abreviaturas
- tipos de tareas
- patrones de pedido
- formas de hablar entre Juanfran, Juanje y Papi

## Archivos

- `PERFIL_EQUIPO.md`
- `PATRONES_OPERATIVOS.md`
- `GUIA_PARA_CLAUDE_CODE.md`

## Uso recomendado

Antes de tocar lógica, prompts o respuestas del bot, conviene leer esta carpeta.

No sustituye a los chats originales, pero sí resume lo más importante para empezar más rápido y con mejor criterio.
