# Cerebro Tatuaje

Base de conocimiento resumida para que la IA de ATOM X OPS entienda mejor:

- terminología de tatuaje
- agujas y cartuchos
- tintas, negros y greywash
- stencil y preparación
- butter, vaselina y aftercare
- cómo razonar preguntas del equipo sin tratar todo como una duda genérica

## Objetivo

No sustituye al catálogo ni al contexto del equipo.

Complementa esos dos bloques con conocimiento del oficio para que la IA:

- entienda mejor lo que se pide
- normalice mejor productos y términos
- responda con más criterio
- detecte mejor funciones y matices
