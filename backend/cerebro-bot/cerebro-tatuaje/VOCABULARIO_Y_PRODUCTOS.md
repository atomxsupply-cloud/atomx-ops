# Vocabulario y productos

## Variantes frecuentes que la IA debería tolerar

- `estencil` = `stencil`
- `dinamik` = `dynamic`
- `kwadrom` = `kwadron`
- `manteka` = `manteca`
- `calca` / `calco` = stencil / transferencia según contexto
- `grande`, `grandote` = formato grande
- `peque`, `pequeño`, `chico` = formato pequeño

## Cómo debe razonar la IA

- no quedarse solo con la marca
- detectar familia + función + formato
- si un nombre está mal escrito, intentar mapearlo a una referencia conocida

## En caso de duda

Si el término es ambiguo, priorizar:

1. familia de producto
2. función dentro del tatuaje
3. formato o tamaño
