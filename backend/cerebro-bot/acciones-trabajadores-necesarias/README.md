# Acciones Trabajadores Necesarias

Aqui se guardan notas de voz o texto pasadas por la IA desde `ATOM X OPS`.

Cada archivo contiene:

- trabajador afectado
- texto original
- resumen ordenado
- problema detectado
- acciones propuestas para revisar o implementar despues

La idea es usar esta carpeta como bandeja de entrada de mejoras, incidencias y bloqueos del equipo.
