## ATOM X Design

Esta carpeta guarda la copia viva de la herramienta publica `atomx-design`
dentro del repositorio principal de `atomx-ops`.

Objetivo:
- centralizar el trabajo en un solo repo
- versionar aqui los cambios funcionales de Design
- mantener la conexion con OPS como backend principal

Notas:
- no guardar secretos aqui
- la IA y el catalogo deben seguir centralizados en OPS
- despliegue publico: `design.atomxsupply.com`
