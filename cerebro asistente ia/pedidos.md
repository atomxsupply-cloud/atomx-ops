# Reglas De Pedidos

## Objetivo

Crear pedidos lo mas rapido posible sin perder informacion clave.

## Prioridades

1. cliente rapido
2. productos rapidos
3. zona correcta
4. urgencia visible
5. guardar sin friccion

## Reglas de cliente

- desde la primera letra deben salir sugerencias
- maximo 5 opciones para no saturar
- si el cliente no existe, se puede crear solo con el nombre
- si existe y cambian datos, se actualiza
- Factusol es la base principal de clientes mientras llega la API real

## Reglas de producto

- permitir meter varias lineas de golpe
- detectar cantidad si la linea empieza por numero
- ofrecer plantillas rapidas de productos recurrentes
- no obligar a rellenar extras innecesarios

## Reglas de interfaz

- primero lo importante: cliente, productos, guardar
- extras ocultos hasta que hagan falta
- muy usable en movil
- botones grandes
- textos claros

## Reglas operativas

- urgente tiene que verse sin abrir el pedido
- la zona debe inferirse si es posible
- si el cliente existe, rellenar telefono y direccion solo
- no bloquear el guardado por no tener todos los datos
